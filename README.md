# Dotfiles

Personal machine setup managed with chezmoi and mise.

## Installation

macOS and Linux:

```bash
curl -fsSL --retry 3 https://raw.githubusercontent.com/aria-amini/dotfiles/main/bootstrap.sh -o bootstrap-dotfiles.sh && bash bootstrap-dotfiles.sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/aria-amini/dotfiles/main/bootstrap.ps1 | iex
```
